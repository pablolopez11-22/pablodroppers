# Italian Street · web

Web de una sola página para Italian Street (Av. Jane Bowles, 17 · Málaga).
HTML + CSS + JS sin dependencias: abre `index.html` en el navegador.

## Estructura
- `index.html`: contenido y secciones
- `css/styles.css`: diseño (colores y tipografías en `:root`)
- `js/main.js`: pestañas de la carta, «Crea tu pasta» y horario. Los **datos editables** (pastas, salsas y horario) están al principio del archivo.
- `img/`: aquí irán las fotos
